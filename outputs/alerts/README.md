# Alerts Output Directory

## Purpose
Stores structured JSON logs of advisory alerts generated by the `alert_engine.py` module during batch evaluation or live simulated telemetry feeds.

## Expected Files
- `alerts_YYYYMMDD_HHMMSS.json`: Machine-readable records containing severity levels (`NORMAL`, `WARNING`, `CRITICAL`), estimated failure probabilities, timestamps, and contributing sensor factors.

## Git Tracking
- Excluded from GitHub commits via `.gitignore`.
