# Dataset Description: UCI AI4I 2020 Predictive Maintenance

## 1. Overview and Provenance
The **AI4I 2020 Predictive Maintenance Dataset** is a synthetic dataset generated by Stephan Matzka (School of Engineering - Technology and Life, HTW Berlin) and hosted on the UCI Machine Learning Repository.
- **UCI Repository URL:** `https://archive.ics.uci.edu/dataset/601/ai4i+2020+predictive+maintenance+dataset`
- **Total Records:** 10,000 instances
- **Task:** Binary classification (predicting equipment failure) and failure mode diagnostics.

## 2. Local File Location and Verification Status
- **Expected Local Path:** `data/raw/ai4i2020.csv`
- **Current Verification Status:** **NOT PRESENT LOCALLY** (Verified via workspace inspection on 2026-10-12). Users must download the file from UCI repository and place it in `data/raw/`.

## 3. Attribute Breakdown

| Column Name | Type | Description | Role in Pipeline |
| :--- | :--- | :--- | :--- |
| `UDI` | Integer | Unique identifier [1 to 10000] | **Dropped** (Non-predictive identifier) |
| `Product ID` | String | Variant letter (L/M/H) + serial number | **Dropped** (Identifier) |
| `Type` | Categorical | Quality variant: L (low, 50%), M (medium, 30%), H (high, 20%) | **Input Feature** (One-hot encoded) |
| `Air temperature [K]` | Continuous | Ambient air temperature (around 300 K) | **Input Feature** (Standard scaled) |
| `Process temperature [K]` | Continuous | Operational temperature (around 310 K) | **Input Feature** (Standard scaled) |
| `Rotational speed [rpm]` | Integer | Spindle rotational speed calculated from power | **Input Feature** (Standard scaled) |
| `Torque [Nm]` | Continuous | Torque distribution normally around 40 Nm | **Input Feature** (Standard scaled) |
| `Tool wear [min]` | Integer | Tool usage duration in minutes | **Input Feature** (Standard scaled) |
| `Machine failure` | Binary (0/1) | Equipment failure indicator | **Target Variable** (`y`) |
| `TWF` | Binary (0/1) | Tool Wear Failure mode | **Excluded** (Target subtype / leakage) |
| `HDF` | Binary (0/1) | Heat Dissipation Failure mode | **Excluded** (Target subtype / leakage) |
| `PWF` | Binary (0/1) | Power Failure mode | **Excluded** (Target subtype / leakage) |
| `OSF` | Binary (0/1) | Overstrain Failure mode | **Excluded** (Target subtype / leakage) |
| `RNF` | Binary (0/1) | Random Failure mode | **Excluded** (Target subtype / leakage) |

## 4. Class Imbalance and Data Leakage Considerations
- **Severe Imbalance:** Approximately 339 of 10,000 instances (~3.4%) are labeled as `Machine failure = 1`. Standard accuracy is an insufficient metric; PR-AUC, F1-score, precision, and recall are required.
- **Leakage Prevention:** Columns `TWF`, `HDF`, `PWF`, `OSF`, and `RNF` explicitly indicate which specific failure occurred when `Machine failure == 1`. Including them as inputs would cause catastrophic label leakage. They are excluded from all model training features.
