# Images Directory

## Purpose
This directory stores verified visual assets, architecture diagrams, and interface screenshots for project documentation.

## Expected Files
- System architecture diagrams (`architecture_diagram.png`)
- Data flow charts
- Streamlit dashboard user interface screenshots

## Git Tracking & Guidelines
- Do not fabricate or invent fake screenshots or evaluation curve images.
- Only commit real, verified visual assets that have been generated from executed runs or created as design diagrams.
