# Processed Data Directory

## Purpose
This directory stores intermediate artifacts, cleaned partitions, and preprocessed matrices generated by the preprocessing pipeline.

## Expected Files
- `train_features.csv` / `test_features.csv`
- `train_target.csv` / `test_target.csv`
- Scaler metadata / transformation maps

## Generation
Generated deterministically by executing:
```bash
python main.py --prepare-data
```
Or running `src/preprocessing.py`.

## Git Tracking
- Do not commit large processed CSVs. They are generated on demand from raw data using code in `src/`.
